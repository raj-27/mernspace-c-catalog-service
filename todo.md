## API Endpoints Overview

### Products

-   [x] **Get Single Product**: Retrieve details for a specific product.
-   [x] **Delete Product**: Remove a product from the catalog.

---

### Categories

-   [x] **Update Category**: Modify details for an existing category.
-   [x] **Get Categories List**: Retrieve a list of all categories.
-   [x] **Delete Category**: Remove a category from the catalog.
-   [x] **Get Single Category**: Retrieve details for a specific category.

---

### Toppings

**Fields:**

-   `name` (string): The name of the topping.
-   `image` (string): URL or path to the topping's image.
-   `price` (number): The price of the topping.
-   `tenantId` (string): Identifier for the associated tenant.
-   `isPublish` (boolean): Publish status of the topping.

**Endpoints:**

-   [x] **Create Topping**: Add a new topping to the catalog.
-   [x] **Update Topping**: Modify details for an existing topping.
-   [x] **Get Toppings List**: Retrieve a list of all toppings.
-   [x] **Get Single Topping**: Retrieve details for a specific topping.
-   [x] **Delete Topping**: Remove a topping from the catalog.
